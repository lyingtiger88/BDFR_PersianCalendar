# BDFR Persian Calendar

Native Persian calendar, planner and reminder platform for Windows 11.

## Goals
- Persian-first calendar with Jalali/Gregorian/Hijri views
- Offline-first occasions database with pluggable sources (including time.ir adapter)
- Events, tasks, notes, recurring reminders and special occasions
- Native Windows notifications and activity history
- WinUI 3 desktop shell designed for Windows 11
- Reusable core for BDFR Lock integration

> Status: active development.
