# picture

Runtime picture assets for BDFR Persian Calendar.

## Structure

- `themes/`
  - `zara-pastel/`
    - `theme.json`
- `theme/`
  - `season backgrounds/`
    - `spring.svg`
    - `summer.svg`
    - `autumn.svg`
    - `winter.svg`
- `event picture/`
  - `default.svg`
  - `birthday.svg`
  - `nowruz.svg`
  - `yalda.svg`
  - `religious.svg`
  - `national.svg`
  - `personal.svg`

`theme/season backgrounds` belongs to Elena Mode and is intentionally independent from any visual theme such as Zara Pastel.

User-selected backgrounds are copied at runtime to:
`%LOCALAPPDATA%\BDFR\PersianCalendar\picture\user background`.
